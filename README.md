# Projeto POO - Simulador de Caravanas no Deserto
Este projeto é um simulador de caravanas desenvolvido para a disciplina de Programação Orientada a Objetos no ISEC (2024/2025). 
O objetivo é gerir caravanas num deserto, interagindo com cidades, enfrentando bárbaros e recolhendo itens, tudo através de comandos no terminal.


###  Funcionalidades
- Mapa do deserto com áreas navegáveis (deserto), montanhas (intransitáveis) e cidades.  

- Gestão de caravanas:
Comprar, vender mercadorias e recrutar tripulantes nas cidades.
Enfrentar combates com bárbaros e sobreviver a tempestades de areia.

- Simulação baseada em turnos:
Comportamentos automáticos para caravanas e eventos aleatórios (itens, combates, etc.).

- Configuração personalizada:
Leitura de ficheiros para definir o mapa inicial e parâmetros do jogo.


### Como Compilar e Executar
Requisitos:
- Compilador C++ compatível com C++20 (GCC, Clang ou MSVC).
- CMake versão 3.29 ou superior.
- CLion IDE (opcional, mas recomendado).

Passos:
- Abra o projeto no CLion.
- Compile o projeto usando o botão Build.
- Execute o programa diretamente no terminal: ./cmake-build-debug/Project_POO
